**Goal:** Patient-scoped PostgreSQL search over archive/document metadata and
canonical extracted text; stop before M14.

   (authorization-bounded queryset, validated filters, dynamic `SearchVector`
   keyword search, deterministic ordering, `select_related` facility chain).

   validation, unknown-param rejection, q length cap) and reuse the M12
   `ArchiveDocumentSerializer` for results.

6. Tests: structured filters, keyword metadata, canonical-text FTS, unicode,

   reflection, concurrency, performance/EXPLAIN, native-PDF e2e, OCR e2e,

   zero, full PG suite (authoritative for search), perf sanity 10,000 docs.
8. Gates: Ruff, format, checks, drift, OpenAPI, `pip check`, Docker compose
